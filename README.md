# Kaboom บูมบอส

เกมตอบคำถามถล่มบอส (ห้องเรียนร่วมมือกัน) — React + TypeScript / Java Spring Boot (WebSocket)

## รัน
Backend (พอร์ต 8080):
    cd backend
    mvn spring-boot:run

Frontend (พอร์ต 5173):
    cd frontend
    npm install
    npm run dev

เปิด http://localhost:5173 แล้วหน้าแรกจะแสดงสถานะการเชื่อมต่อ backend (GET /api/health)
